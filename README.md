# First-term Projects
A collection of projects made during my first term of college

## Text Adventure
A Python text adventure game where players explore various areas, interact with NPCs, collect items, and make choices that affect the outcome. The goal is to progress through the story and achieve the highest possible score.

## CitySim
A Python city-building simulation game where players expand their city by constructing houses, roads, and rivers while managing population and revenue. Random events like floods and meteor showers add dynamic challenges.

## Marbles
This Python program simulates bouncing marbles that stop and change color when touching a stuck marble. The marbles move randomly, with collisions detected based on distance, and a color gradient is applied to marbles near the center. When all marbles are stuck, a new batch is created.

## Land Generation
A Python terrain generation program that creates a random landscape with various land types such as mountains, grass, water, and sand based on a seed value. The grid is initialized with random corner values, and the land types are recursively determined and displayed using color coding.
